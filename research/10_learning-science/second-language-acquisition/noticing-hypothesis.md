# Noticing Hypothesis

## Summary
The Noticing Hypothesis (Schmidt, 1990, 2001, 2010) proposes that learners must consciously notice linguistic features in input for acquisition to occur. Strong claim (1990): subliminal language learning is impossible. Weakened (2001): more noticing leads to more learning. Extended by Gass with noticing the gap -- learners must notice discrepancies between their interlanguage and target forms. Influential but contested -- critics argue implicit learning is the default SLA mechanism.

## What We Know
- Strong claim is not well supported; Schmidt 2010 acknowledges evidence against it.
- Weak claim has more support: noticing facilitates and accelerates acquisition.
- Noticing applies to surface forms (words, morphemes, constructions), not abstract rules (Schmidt 2001).
- Triggered by: instruction, perceptual salience, frequency, skill level, task demands, comparing.
- Input enhancement (bolding, highlighting) can increase noticing.
- Methodological challenges plague the field: measuring a brief cognitive event is difficult.
- Key critics: Truscott (should be limited to metalinguistic knowledge), Krashen (most acquisition is subconscious).

## Design Relevance
### For VibeLingo show-me-why feature
The Noticing Hypothesis is the primary theoretical justification for explicit language feedback. The user preference for show-me-why aligns with what the hypothesis predicts will help. However, strength of support depends on which version you accept.

### Specific design implications
1. show-me-why is justified but not sufficient: explicit attention helps but acquisition requires repeated exposure and implicit processing.
2. Surface-level focus: highlight specific word forms and constructions, not abstract grammar rules.
3. Input enhancement as low-friction noticing: bolding, highlighting, color-coding target forms without stopping workflow.
4. Noticing the gap: juxtapose user output with correct form -- likely the most powerful explicit feedback mechanism.
5. Timing matters: during complex tasks, save explicit feedback for task boundaries or review moments.
6. Frequency and salience: repeated exposure across sessions increases noticing probability.
7. User preference alignment: show-me-why is a theoretically grounded pedagogical choice, not just a UX preference.

### Implicit vs. explicit tension
VibeLingo navigates a fundamental tension:
- Explicit attention (noticing): best for low-salience grammatical features, irregular forms, features differing from L1.
- Implicit exposure: best for high-frequency, high-salience features and developing fluency.
- Practical implication: show-me-why should target specific, learnable forms unlikely to be acquired through exposure alone.

## Risks / Misuses
- Over-noticing: flagging every error causes cognitive overload and disengagement.
- Metalinguistic overload: grammar rule explanations for every error are counterproductive.
- Frustration vs. motivation: constant correction may demotivate some users.
- Noticing vs. learning confusion: noticing does not equal acquisition.
