# Involvement Load Hypothesis: Task-Induced Involvement and Vocabulary Retention

## Metadata

- Type: paper
- Date captured: 2026-07-07
- Source URL: https://doi.org/10.1093/applin/22.1.1 (Applied Linguistics, Oxford University Press)
- Authors: Jan H. Hulstijn, Batia Laufer
- Year: 2001
- Reliability: high (widely cited, replicated, has stood the test of time)
- Tags: sla, vocabulary-acquisition, involvement-load, task-design, incidental-learning

## Why It Matters

The Involvement Load Hypothesis provides a practical framework for predicting how much vocabulary learning a task will produce based on its design. It identifies three dimensions (Need, Search, Evaluation) that VibeLingo can use to evaluate and enhance the vocabulary-learning potential of different agent-session activities.

## Key Claims

- Vocabulary retention is determined by the **Involvement Load** of the task during which the word was encountered.
- Three components of Involvement Load:
  - **Need**: The drive to understand or use a word (moderate → strong).
  - **Search**: The attempt to find the meaning of an unknown word (absent → present).
  - **Evaluation**: Comparison of a word with other words, or assessment of its contextual fit (absent → moderate → strong).
- **Tasks with higher Involvement Load produce significantly better vocabulary retention**.
- **Writing (composition) tasks produce the best retention** because they involve strong Need + strong Evaluation.

## Evidence / Details

- Two experiments: one in Israel (advanced EFL learners), one in Netherlands (intermediate EFL learners).
- Three task conditions: reading with marginal glosses, reading + gap-fill, composition writing with target words.
- Results: composition > gap-fill > reading only on both immediate and delayed (1-2 week) posttests.
- Effect was consistent across proficiency levels.
- The hypothesis does NOT claim these three factors are the ONLY factors; it's a parsimonious minimum.
- Subsequent research has largely supported the ILH with some refinements and additions.

## Implications for VibeLingo

- **User output (writing) is the highest-value learning activity**: When the user writes code comments, agent prompts, or documentation in the target language, involvement is maximized.
- **Agent responses are mid-involvement**: Reading agent output involves Need (comprehension required) but minimal Search (no look-up) or Evaluation (no comparison).
- **VibeLingo can artificially increase involvement**: Providing definitions (adding Search), asking the user to choose between alternatives (adding Evaluation), or prompting the user to use a new word in their next message (adding strong Need).
- **Vocabulary capture priority should follow involvement**: User-authored words (highest priority) > words the user looked up (mid priority) > words the user passively read (lowest priority).

## Limitations

- Only tested on English as L2.
- Short-term studies (1-2 weeks delayed test).
- Does not address individual differences (working memory, motivation, learning strategies).
- Simpler models (e.g., just "amount of mental effort") might explain the same data.

## Follow-up Questions

- Can VibeLingo inject Evaluation into agent-session interactions without disrupting flow?
- What is the Involvement Load of composing an agent prompt in L2 (the user's primary use case)?
- How do different types of coding activities map to the three ILH dimensions?
