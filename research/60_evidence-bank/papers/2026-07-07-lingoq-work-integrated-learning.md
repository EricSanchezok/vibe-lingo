## Why It Matters
HIGHLY relevant. LingoQ embeds language learning into work context via LLM queries. This is the closest existing system to VibeLingo. Three-week deployment study with 28 EFL workers.

## Key Claims
- EFL workers struggle to sustain learning despite motivation because study materials are disconnected from work context.
- Workers already use LLMs for language queries at work, but these interactions do not contribute to learning.
- LingoQ captures LLM queries and auto-generates personalized quizzes for later review.
- Participants consistently engaged over 3 weeks; saw it as more sustainable than prior methods.
- Self-efficacy improved 9.5% (p<0.001); beginners showed notable learning gains.
- Contextual relevance of quizzes was the key value driver.

## Evidence / Details
- Formative study: 49 workers. Main pain points: lexical disruptions, low confidence, disconnected study materials.
- 3-week deployment: 28 workers. Quizzes generated from their actual LLM queries.
- Automated quality checking via AI pipeline.
- Measured self-efficacy, engagement, learning outcomes.

## Implications for VibeLingo
- STRONG validation of VibeLingo core thesis: work-integrated language learning is more engaging and sustainable.
- Workers want to learn but current tools fail them ¡ª exactly the gap VibeLingo fills.
- The quiz review feature (later micro-practice) is a proven pattern.
- Contextual relevance > generic materials ¡ª VibeLingo deepens this by embedding in live sessions.
- Workers already use LLMs for language help; VibeLingo systematizes this.

## Limitations
- 3 weeks is short for measuring sustained motivation.
- Korean EFL workers only; may not generalize to all language pairs.
- Quiz format may not suit all learning preferences.

## Follow-up Questions

- Would the approach work for languages other than English?
