# EDEN: Empathetic Dialogues for English Learning

## Metadata
- Type: paper
- Date captured: 2026-07-07
- Source URL: arXiv:2406.17982
- Authors: Li Siyan, Teresa Shao, Zhou Yu, Julia Hirschberg (Columbia University)
- Year: 2024
- Reliability: medium (preliminary user study)
- Tags: sla, chatbot-learning, motivation, grit

## Why It Matters
Directly tests whether empathetic chatbot feedback improves L2 grit and persistence. Shows a pathway for VibeLingo agent to provide affective support.

## Key Claims
- Perceived affective support (PAS) from teachers predicts higher student L2 grit.
- Hypothesized that the same pattern applies to chatbots.
- Built EDEN: open-domain chatbot with grammar correction + empathetic feedback.
- Adaptive empathetic feedback led to higher perceived affective support.
- Elements of perceived affective support positively correlated with student grit changes.

## Evidence / Details
- Preliminary user study comparing three empathetic feedback strategies.
- Adaptive strategy (context-sensitive) outperformed fixed and no-empathy conditions.
- Built specialized spoken-utterance grammar correction model.
- Open-domain chitchat across multiple topics.

## Implications for VibeLingo
- The Synergy agent should use empathetic, adaptive feedback ¡ª not just corrections.
- Affective tone matters: warmth and empathy from the agent can improve persistence.
- Supports the idea that agent personality matters for motivation.
- Key question: can we make the agent empathetic without it feeling fake or patronizing?

## Limitations
- Preliminary user study, small scale.
- Correlation not causation established between PAS and grit.
- Open-domain chatting, not task-embedded conversation like VibeLingo.

## Follow-up Questions
- What specific empathetic strategies work in task-embedded contexts?
- Can agent empathy be calibrated to learner preferences?
- Does empathetic feedback interact with proficiency level?
