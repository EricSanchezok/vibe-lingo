# VibeLingo

VibeLingo is a prompt-first English coaching plugin for Synergy. It keeps the primary Agent focused on real work while adding brief, high-value English corrections and privately tracking recurring patterns.

## Requirements

- Synergy `>=3.0.0`
- Bun `>=1.3.0`

## What It Does

VibeLingo has two independent paths:

1. A system-transform hook gives the primary Agent a compact work-first coaching contract.
2. A continuing user-message observer asks a private hidden Agent to extract structured English-learning signals after the message has already been submitted.

Clear tasks continue immediately. Genuine task ambiguity is clarified. Correct English, ordinary Chinese instructions, child Sessions, small internal calls, and escape-hatch messages stay out of the teaching flow.

VibeLingo does not provide Composer completion, submission interception, inline editor decorations, a dashboard, vocabulary review, or spaced repetition.

## Install for Local Development

```bash
bun install
bun run build
synergy plugin add file:///Users/eric/projects/vibe-lingo
synergy plugin approve vibe-lingo
```

For isolated development:

```bash
export SYNERGY_HOME="$(mktemp -d)"
bun run dev -- --server-url http://127.0.0.1:PORT
```

## Settings

Synergy exposes a native VibeLingo settings section:

```jsonc
{
  "correctionMode": "focused", // focused | strict | off
  "trackingEnabled": true,
  "recurringFocusEnabled": true,
}
```

- `focused` corrects meaning-affecting, clearly unnatural, and recurring issues, with at most one compact correction.
- `strict` corrects every certain English error, with at most two compact corrections.
- `off` disables foreground coaching without deleting or disabling background tracking.
- Turning tracking off stops new analysis but retains existing local data.

Say `just do it`, `skip the lesson`, `直接做`, or `跳过纠正` to suppress coaching and persistence for that message.

## Progress

When the user explicitly asks about English progress, recurring mistakes, or historical examples, Synergy can discover:

```text
plugin__vibe-lingo__progress
```

It can report global or current-Scope counts and optionally show up to three sanitized examples with Scope, Session, and message provenance. It does not estimate proficiency or claim that a pattern has been mastered.

## Data and Privacy

VibeLingo stores its SQLite database at:

```text
<SYNERGY_HOME or home>/.synergy/data/plugins/vibe-lingo/vibe-lingo.sqlite
```

The plugin never persists complete user messages or Agent responses. It stores:

- normalized error-pattern metadata;
- occurrence counts and timestamps;
- Scope, Session, and message IDs;
- at most five recent sanitized fragment pairs per pattern.

Fragments that appear to contain URLs, email addresses, private absolute paths, credentials, long tokens, or code blocks are omitted while aggregate provenance is retained.

A normal plugin uninstall deletes the VibeLingo data directory. Synergy force uninstall skips lifecycle cleanup and may leave the directory behind.
