# VibeLingo

VibeLingo is a Synergy plugin concept for learning languages naturally inside agent workflows.

## Positioning

People increasingly start their computer work through agents: vibe coding, vibe research, vibe writing, planning, reading, and daily problem solving. VibeLingo turns those agent sessions into lightweight language-learning moments without forcing users into a separate learning app.

## Core Idea

Make language learning happen in the flow of agent work:

- Help users learn any target language, not only English.
- Detect useful language-learning opportunities from the current conversation.
- Turn real user intent into contextual vocabulary, phrases, corrections, practice prompts, and micro-lessons.
- Keep the experience motivating, low-friction, and agent-native.

## Name

**VibeLingo** combines:

- **Vibe**: the modern agent-native workflow style, such as vibe coding and vibe research.
- **Lingo**: informal, approachable language learning across many languages.

Working plugin id / folder name:

```txt
vibe-lingo
```

## Early Design Questions

- Should VibeLingo behave mostly as explicit tools, proactive agent suggestions, or both?
- How should users choose source language, target language, level, and preferred learning style?
- What should the first minimum useful feature be?
- Should it store learner progress inside Synergy plugin config/data, or stay stateless at first?
